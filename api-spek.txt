INFORMASI UMUM
--------------
Base URL (Local Dev) : http://[IP_LAPTOP_ATAU_10.0.2.2]:8000/api/v1
Format Data           : JSON (kecuali upload berkas/foto menggunakan multipart/form-data)
Zona Waktu            : Asia/Jakarta (WIB)
Standar Header Request:
  - Accept        : application/json (Wajib di semua request)
  - Content-Type  : application/json (Gunakan multipart/form-data jika mengunggah file)
  - Authorization : Bearer <ACCESS_TOKEN> (Wajib untuk semua endpoint berproteksi)

Format Standar Response Sukses:
{
  "success": true,
  "message": "Pesan sukses deskriptif",
  "data": { ... } // Objek atau Array data
}

Format Standar Response Error:
{
  "message": "Deskripsi pesan kesalahan",
  "code": "KODE_ERROR", // Contoh: VALIDATION_ERROR, UNAUTHENTICATED, FORBIDDEN, NOT_FOUND
  "errors": { ... } // Detail error validasi per field (jika ada)
}

Kode Status HTTP:
- 200 OK                    : Permintaan berhasil diproses.
- 201 Created               : Sumber data baru berhasil dibuat.
- 400 Bad Request           : Parameter atau input tidak valid.
- 401 Unauthorized          : Belum login, token tidak ada, atau sesi berakhir.
- 403 Forbidden             : Role akun tidak memiliki izin akses (kewenangan ditolak).
- 404 Not Found             : Data tidak ditemukan atau rute salah.
- 422 Unprocessable Content : Validasi gagal (misal field kurang atau aturan bisnis dilanggar).
- 500 Internal Server Error : Kesalahan internal pada server.

BAGIAN 3: PRESENSI & JADWAL KERJA (ATTENDANCE) - MOBILE ONLY
================================================================================

Aturan Bisnis Presensi:
1. Hanya dilakukan melalui aplikasi Mobile React Native (tidak tersedia di Web Portal).
2. Memerlukan verifikasi koordinat GPS (Geofencing radius 100m dari kantor) dan foto wajah selfie.
3. Karyawan regular wajib check-in pada shift regular. Karyawan shifting wajib memilih shift shifting.
4. Keterlambatan dihitung otomatis jika check-in melewati jam mulai shift.

3.2. Check-In Presensi (Masuk)
------------------------------
Endpoint : POST /attendances/check-in
Auth     : Bearer Token
Header   : Content-Type: multipart/form-data
Deskripsi: Melakukan absen masuk dengan validasi AI biometrik wajah dan geofence GPS.

Form-Data Request:
- latitude       : -6.2087634 (numeric, required) - Koordinat latitude perangkat
- longitude      : 106.845599 (numeric, required) - Koordinat longitude perangkat
- shift_id       : 1 (integer, optional/required jika shifting worker)
- face_photo     : [File Image, image/jpeg, max: 4MB, required] - Foto selfie kamera depan

Response 200 OK (Presensi Berhasil):
{
  "success": true,
  "message": "Check-in berhasil tercatat.",
  "data": {
    "attendance_id": 143,
    "attendance_date": "2026-11-05",
    "check_in_time": "2026-11-05 07:55:10",
    "status": "hadir",
    "late_minutes": 0,
    "face_score": 96.8,
    "face_verified": true,
    "review_status": "disetujui"
  }
}

Response 422 Unprocessable Content (Contoh: Di Luar Radius Kantor):
{
  "message": "Anda berada di luar area kantor yang diizinkan (Radius maksimal 100m).",
  "code": "GEOFENCE_OUT_OF_RANGE",
  "errors": {
    "location": ["Jarak Anda saat ini 450 meter dari kantor."]
  }
}

Response 422 Unprocessable Content (Contoh: Wajah Tidak Cocok):
{
  "message": "Verifikasi wajah gagal. Skor kecocokan di bawah batas minimal 80%.",
  "code": "FACE_VERIFICATION_FAILED",
  "errors": {

  }
}

BAGIAN 6: KODE ERROR SPESIFIK SISTEM (ERROR CODES)
================================================================================

Ketika server merespons dengan status HTTP error, field `code` pada body respons
memiliki arti sebagai berikut untuk penanganan UI di Frontend:

- VALIDATION_ERROR            : Input form tidak sesuai aturan validasi Laravel.
- UNAUTHENTICATED             : Token tidak disertakan atau sesi telah habis (Arahkan ke layar Login).
- FORBIDDEN                   : Pengguna tidak memiliki wewenang role untuk aksi ini.
- NOT_FOUND                   : Entitas atau endpoint tidak ditemukan.
- GEOFENCE_OUT_OF_RANGE       : Koordinat GPS mobile berada di luar batas jarak kantor (radius > 100m).
- FACE_VERIFICATION_FAILED    : Wajah tidak terdeteksi atau tingkat kemiripan < 80%.
- INSUFFICIENT_LEAVE_BALANCE  : Sisa kuota cuti tahunan tidak mencukupi permohonan.
- SHIFT_NOT_ALLOWED           : Karyawan regular memilih shift shifting atau sebaliknya (Trigger DB).
- REQUEST_CANNOT_BE_CANCELLED : Permohonan tidak bisa dibatalkan karena sudah diproses.
- TOO_MANY_REQUESTS           : Terlalu banyak percobaan dalam waktu singkat (Rate Limiting).
